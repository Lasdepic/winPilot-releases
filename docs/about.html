À propos

Sous Windows, chaque application se met à jour à sa façon. WinPilot les réunit au même endroit.

Pourquoi WinPilot

Windows inclut déjà un gestionnaire de paquets très complet, winget, mais il s'utilise en ligne de commande. WinPilot lui donne une interface simple : on voit ce qui est à jour, on coche, on valide.

Comment ça marche

WinPilot lance winget sur votre PC et affiche ses résultats. Les applications viennent donc des sources de winget, et non d'un serveur de WinPilot.

Seule exception : Sidekick, qui n'est pas dans winget, s'installe depuis son dépôt GitHub.

Vos données

  • Pas de compte ni d'inscription.
  • Pas de télémétrie ni de statistiques d'utilisation.
  • Vos réglages et votre historique restent sur votre PC.
  • WinPilot se connecte à Internet pour winget, pour chercher ses propres mises à jour sur GitHub et pour télécharger les applications que vous demandez.

Configuration requise

  • Windows 10 ou 11
  • winget (« App Installer »)

Questions fréquentes

Pourquoi Windows affiche un avertissement à l'installation ?

L'installeur n'est pas signé avec un certificat de code, donc SmartScreen ne connaît pas son éditeur. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».

Comment WinPilot se met-il à jour ?

Il cherche une nouvelle version au démarrage puis toutes les 6 heures, et la télécharge. C'est vous qui choisissez quand l'installer.

Puis-je ignorer une application ?

Oui, vous pouvez ignorer une application ou seulement une version précise.

WinPilot fonctionne-t-il sur Mac ou Linux ?

Non, il repose sur winget, qui n'existe que sous Windows.
